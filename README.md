# 📊 Interactive Sales Dashboard (Excel + Power Query)

## 📌 Project Overview
This project is an interactive Sales Performance Dashboard created using Microsoft Excel and Power Query. It helps analyze sales trends, product performance, regional performance, and key business KPIs.

## 🛠️ Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## 📈 Dashboard Features
- Sales KPI Cards
- Monthly Sales Analysis
- Region-wise Performance
- Product-wise Sales
- Interactive Filters (Slicers)
- Dynamic Charts

## 🎯 Skills Demonstrated
- Data Cleaning
- Data Transformation
- Dashboard Design
- Business Reporting
- Data Visualization
